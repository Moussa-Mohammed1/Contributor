# contributor

**contributor** is a production-grade, AI-powered automation system that
continuously improves existing Git repositories through small, meaningful,
fully-automated commits.

It is **not** a fake-GitHub-activity generator. Every commit produced by
`contributor` is the result of a real, verifiable improvement (documentation,
refactoring, dead-code removal, formatting, lint fixes, small bug fixes, test
improvements and more) generated by an AI engine that first *analyzes* the
repository and then proposes and applies only genuine changes.

## Features

- Manage **unlimited repositories** with weighted, priority-based selection.
- Multiple **active schedules** with configurable periods, timezones and working days.
- **Background execution** via an always-on daemon (Windows / Linux / macOS).
- **Crash recovery**: resumes exactly where execution stopped, never duplicates
  commits, never loses state.
- **Local analysis engine** that inspects language, framework, build system,
  package manager, formatters, linters and tests before calling an LLM.
- **AI improvement engine** with 6 providers (OpenAI, Gemini, Claude, Ollama,
  LM Studio, OpenRouter) behind a single provider abstraction.
- **Safety system**: formatter / linter / optional tests must pass before a
  commit is created; anything that fails rolls the working tree back.
- **Safe Git engine**: dirty-tree detection, staging isolation, conflict /
  stash / merge detection, untracked-file handling, never overwrites user work.
- **Semantic commit messages** (`docs:`, `fix:`, `refactor:`, …) generated from
  real modifications.
- **State database** (SQLite + SQLAlchemy) storing schedules, plans, history,
  prompts, responses, failures and statistics.
- **Modern desktop GUI** (Textual) with Dashboard, Repositories, Schedules,
  Logs, Statistics, AI Providers, Configuration, Notifications and Settings.
- **Desktop notifications** for schedule start, commit completion, push
  failures, unhealthy repositories and schedule completion.
- **Statistics** with daily / weekly / monthly activity, per-repository
  activity, AI success rate and execution times.
- **Dry-run mode**, **`keeper doctor`** diagnostics and a **local HTTP API**.
- Docker support and Windows executable builds.

## Quick start

```bash
pip install -e ".[dev]"
keeper init
keeper config edit
keeper start
keeper status
keeper dry-run          # simulate a full day without touching anything
keeper gui              # desktop dashboard
```

## Command reference

```
keeper init            Initialize configuration, database and directories
keeper start           Start the background scheduler daemon
keeper stop            Stop the background scheduler daemon
keeper status          Show daemon + today's plan status
keeper schedule        Show today's and upcoming execution plans
keeper repositories    List configured repositories and health
keeper logs            Tail structured logs
keeper doctor          Run a full environment / repository diagnostic
keeper dry-run         Simulate an entire execution day with no side effects
keeper config          Show / edit / validate configuration
keeper stats           Print statistics
keeper api             Start the local HTTP API
keeper gui             Launch the Textual desktop dashboard
```
